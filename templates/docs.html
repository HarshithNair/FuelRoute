FUELROUTE / DEVELOPER REFERENCE

A clearer road ahead.

One endpoint for the driving route, a cost-optimized fuel plan, and an auditable fuel balance.

POST /api/route/

Send JSON with US locations. The optional starting fuel price values the fuel already in the vehicle; otherwise the mean price in the imported US dataset is used. There is no API key for this local assessment; the endpoint is limited to 30 requests/minute per IP.

{
  "start": "New York, NY",
  "finish": "Los Angeles, CA",
  "initial_fuel_price": "3.500"
}
curl -X POST http://127.0.0.1:8000/api/route/ \
  -H 'Content-Type: application/json' \
  -d '{"start":"New York, NY","finish":"Los Angeles, CA"}'

Response fields

  • start, finish: resolved location names and coordinates.
  • distance_miles, duration_hours: base OSRM driving route; no station detours or refueling time.
  • total_distance_miles, detour_miles, total_gallons: journey estimates including modeled station access.
  • fuel_stops: station ID, name, city/state, coordinates, progress along route, source price, gallons purchased, rounded cost, coordinate provenance and estimated detour.
  • legs: origin/destination station IDs, modeled distance, fuel departure and arrival. Every returned leg is at most 500 miles.
  • initial_fuel_cost, fuel_purchase_cost, total_fuel_cost: consumed starting fuel plus the sum of rounded station purchases.
  • route_geometry: GeoJSON-order [[longitude, latitude], …] for the base route.
  • data_coverage, candidate_stations, assumptions: coverage and interpretation of the estimate.
Fuel assumptions

A full initial 50-gallon tank, 10 MPG, and a 500-mile range. Short journeys need no stop. Starting fuel remaining after a short trip is not charged. Longer trips finish with an empty tank in the mathematical model. Station access is estimated locally; actual detour road distances are not verified.

Errors

{"error": {
  "code": "no_reachable_station",
  "message": "There is a gap longer than 500 miles between usable fuel stops.",
  "details": {"detail": "..."}
}}
  • 400 — invalid JSON, empty inputs, identical text inputs, or invalid starting fuel price.
  • 422 — unresolved/outside-US locations, same resolved location, no road route, or missing reachable stations.
  • 429 — request rate limit exceeded; check Retry-After.
  • 503 — missing fuel data, provider failure, solver time limit, or candidate limit exceeded.

GET /api/status/

Returns imported and located station counts, data readiness, range, and MPG. Imported data can be ready while coordinate coverage remains incomplete.

One route request

Up to two cached location lookups plus one cached OSRM driving request. Station matching, distance projection and fuel optimization run locally. No routing request is made per station. Coordinate enrichment is a separate management command.
